2. Codebase Originality & Algorithmic Independence

The code in scripts/ was audited for intellectual independence against public GitHub repositories and reference implementations:

  • Leak-Free Cross-Validation Pipeline: 100% custom-implemented. Preprocessing transforms (imputation, scaling, one-hot encoding) are encapsulated strictly inside training folds to guarantee zero leakage.
  • HPEM Methodological Adaptation: The original paper pseudocode trained its meta-learner on the same training data (resubstitution leakage). Our implementation developed a 3-fold out-of-fold meta-training architecture, correcting this flaw. This represents independent algorithmic derivation.
  • Clinical Decision Curve Analysis (DCA): Custom Net Benefit evaluation module (run_decision_curve_analysis.py) developed from first principles following the Vickers & Elkin formulation.
  • Missingness Indicator Innovation: Custom experimental design comparing standard median/mode imputation against missingness-augmented feature spaces across 5 hospital sources.
  • Subgroup Confidence Intervals: Independent implementation of exact 95% Wilson score intervals and Hanley-McNeil variance formulas for clinical stratification.
